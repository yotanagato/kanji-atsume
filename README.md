# かんじあつめ

小学1年生で習う漢字80字を、さかなつり／カードの2つの遊びかたで覚える知育Webアプリです。

**遊ぶ → https://yotanagato.github.io/kanji-atsume/**

- 単一HTML完結・依存ライブラリなし・PWA（ホーム画面に追加してオフラインでも遊べます）
- 出題は3種類：よみ→かんじ ／ かんじ→よみ ／ ことばの穴うめ
- まちがえても減点なし。**正解するまで同じ問題に挑戦できます**
- 苦手な字ほど多く出題（ライトナー箱）。集めた字は「かんじずかん」で金色になります
- 成績はブラウザのローカルストレージにのみ保存されます（サーバーへの送信なし）

対象漢字は文部科学省「学年別漢字配当表」1年の80字です。

詳しい仕様は [SPEC.md](SPEC.md) を参照してください。
